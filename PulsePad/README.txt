PulsePad
A custom macropad using a Seeed XIAO RP2040

Features
-4 reprogrammable keys
-Reprogrammable Rotary Encoder
-OLED display
-Media control layer
-Arrow key layer

Layer 0 (Media control layer)
                 MUTE          Rotary Encoder (Turn for volume, click to change layers)
Prev. Track    Play/Pause    Next Track        


Layer 1 (Arrow key layer)
              Up Arrow       Rotary Encoder (Turn for scrolling, click to change layers)
Left Arrow   Down Arrow   Right Arrow        

Hardware
-Seeed XIAO RP2040
-EC11 Rotary Encoder
-128x32 OLED

OLED States
Layer 0: Media
Layer 1: Arrows
